A newspaper front page summing up Monday 23 November 2026, drawn entirely in
code. `main.ts` (Node 22, standard library only) rasterises the page — a
hand-written PNG encoder, a small bitmap font, and shapes for every picture —
and writes one 1024×1024 image to `/output/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`).

Run it with:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
